# Business KPI Analysis

## Overview
This project analyses sample business data using Python and Pandas to calculate key business performance indicators (KPIs).

## KPIs Analysed
- Revenue
- Revenue Growth Rate
- Customer Churn Rate
- Average Order Value

## Tools Used
- Python
- Pandas
- Visual Studio Code

## Files
- `business_data.csv` – Sample business dataset.
- `business_kpi.py` – Python script for calculating and analysing KPIs.
- `kpi_summary.html` – HTML report displaying the KPI summary with colour coding.

## How to Run

1. Install Python.
2. Install Pandas using:

   `python -m pip install pandas`

3. Open the project folder in VS Code.
4. Run:

   `python business_kpi.py`

## Key Findings
- Revenue increased by 12% from February to March.
- Revenue growth improved from 7.14% to 12%.
- Customer churn increased slightly from 4.31% to 4.62%.
- Average order value increased from KES 2,343.75 to KES 2,400.
