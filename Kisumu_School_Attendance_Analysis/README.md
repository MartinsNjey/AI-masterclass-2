# Kisumu School Attendance Analysis

## Overview
This is a Multi-Dataset Analysis school attendance and infrastructure data from selected schools in Kisumu County using Python, Pandas, NumPy and Matplotlib.

## Objectives
- Examine average school attendance.
- Compare school infrastructure, including the number of classrooms and water access.
- Combine attendance and infrastructure datasets.
- Explore the relationship between classroom numbers and attendance.

## Key Findings

1. Nyamasaria Primary and Manyatta Primary recorded the highest average attendance at 90%.
2. Kondele School recorded the lowest average attendance at 72%.
3. The analysis reported a positive correlation of approximately 0.69 between classroom numbers and average attendance.

## Office Report Finding

The analysis indicates that schools with more classrooms generally recorded higher average attendance, with a correlation of approximately 0.69, although this does not establish a cause-and-effect relationship.

## Requirements
- Python
- Pandas
- NumPy
- Matplotlib

## How to Run

1. Install the required packages:

   `python -m pip install pandas numpy matplotlib`

2. Run the analysis:

   `python school_analysis.py`
