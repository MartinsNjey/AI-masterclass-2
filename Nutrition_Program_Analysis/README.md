# Nutrition Program Analysis

## Overview

This Multi-Dataset analyses six months of nutrition program outcomes across Nairobi, Kisumu, and Nakuru counties, using Python, Pandas and Matplotlib.

The analysis focuses on:
- Average weight gain by county.
- The relationship between sessions attended and weight gain.
- Weight gain differences across participant age groups.

## Files

- `nutrition_data.csv` - The nutrition program dataset.
- `analysis.py` - Python script used to analyse the data.
- `findings_report.md` - Summary of the three main findings.
- `county_performance.png` - County performance chart.
- `attendance_vs_weight_gain.png` - Attendance and weight gain chart.
- `average_weight_gain_by_age.png` - Age group comparison chart.

## Key Findings

### 1. County Performance
Participants in Kisumu recorded the highest average weight gain, followed by Nakuru and Nairobi.

### 2. Attendance and Weight Gain
Participants who attended more nutrition sessions tended to achieve greater weight gain.

### 3. Age Group Performance
Younger participants recorded higher average weight gain than older participants, especially teenagers.
