# Sales Performance Dashboard

## Otieno Wholesale Supplies

An interactive dashboard built with Python, Pandas and Streamlit to track wholesale sales performance by county and month.

## Features

- Filter sales by county and month
- View total revenue, total orders and average order value
- Visualize monthly revenue trends
- Identify top customer accounts
- Analyze dormant customers

## Requirements

- Python 3
- Streamlit
- Pandas

## How to Run

1. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the dashboard:

   ```
   streamlit run app.py
   ```
